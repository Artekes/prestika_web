# Prestika — prezentační web

Jednostránkový statický web školní firmy Prestika. Otevřete `index.html` přímo v prohlížeči nebo nasměrujte statický hosting na kořen projektu; není potřeba instalovat závislosti ani spouštět build.

## Struktura

- `index.html` obsahuje úvod, nabídku, ukázky produktů, připravovaný katalog, historii firmy a kontakt. Navigace vede na sekce pomocí kotev.
- `head.css` obsahuje barvy a společné designové tokeny převzaté z původní palety.
- `main.css` obsahuje rozvržení, komponenty a responzivní pravidla pro telefon i desktop.
- `img/` obsahuje optimalizované kopie loga, produktových fotografií a fotografie týmu z dodaných podkladů.
- `materials/` jsou původní podklady; web používá jen vybrané materiály.

HTML a CSS obsahují komentáře k hlavním částem, aby se v nich dalo snadno orientovat při další úpravě. Kontaktní údaje pocházejí z dodané vizitky. Katalog je připravený na PDF, které zatím nebylo dodáno; komentář v HTML popisuje, jak později vložit odkaz ke stažení.
